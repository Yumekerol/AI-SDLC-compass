Requisitos: AI-SDLC Compass


Prioridade segundo MoSCoW (Must / Should / Could).
A coluna UC indica o caso de uso de onde vem o requisito (numeração do UseCases.txt). -> vai se atualizando com os casos de uso

2. NÃO FUNCIONAIS
ID	Categoria	Requisito
RNF01	Âmbito	O PoC suporta repositórios até ≈50 ficheiros e apenas Python, JavaScript e Java
RNF02	Âmbito	Os inputs da equipa são auto-declarados, sem integração com ferramentas de gestão de projeto
RNF03	Desempenho	O scan de um repositório de ≈50 ficheiros termina em menos de 1 minuto (valor a validar)
RNF04	Desempenho	A geração do diagnóstico termina em menos de 3 minutos (valor a validar)
RNF05	Fiabilidade	Perante falhas (GenAI indisponível, quota, resposta mal formatada, rede, geração do PDF), o sistema mostra mensagem clara, faz retentativas controladas e preserva os dados já introduzidos
RNF06	Segurança e privacidade	O código é guardado apenas numa área temporária e eliminado após o scan
RNF07	Segurança e privacidade	Não é enviado código completo ao GenAI, apenas sinais ou excertos, quando aplicável
RNF08	Segurança e privacidade	Chaves de API e tokens de repositório não são guardados no código nem persistidos em claro
RNF09	Usabilidade	Um Delivery Manager sem formação técnica profunda consegue preencher o formulário e obter o relatório sem apoio
RNF10	Qualidade do output	O diagnóstico segue sempre a mesma estrutura (6 fases, campos fixos), validada automaticamente
RNF11	Qualidade do output	Cada recomendação é rastreável a um sinal ou input (sem recomendações sem justificação)
RNF12	Qualidade do output	O PDF tem aspeto profissional e pode ser usado diretamente numa reunião com cliente
RNF13	Rastreabilidade	Cada diagnóstico guarda a versão do prompt, o modelo e a data de geração
RNF14	Manutenibilidade	Os prompts e o template do relatório ficam em ficheiros próprios, fora do código
RNF15	Extensibilidade	Adicionar uma linguagem ao scanner ou trocar o fornecedor de GenAI não obriga a reescrever o resto do sistema
RNF16	Custo	O sistema limita tokens e custo por diagnóstico
RNF17	Documentação	As limitações do PoC e o caminho para enterprise ficam documentados no sistema e na documentação técnica



3. PERGUNTAS IMPORTANTES
    Idioma do relatório: inglês ou português?
    Tempos aceitáveis: os valores de RNF03 e RNF04 são realistas?
    Privacidade: podemos enviar excertos de código ao GenAI, ou só sinais agregados? (RF26, RNF07)
    Interface: aplicação web, CLI ou outra?
    Agentes e chatbot: querem RF-A e RF-B, ou só formulário + scan + relatório?
